# Marmut

Marmut is a Discord music bot powered by Lavalink and Shoukaku.

## Requirements

- Node.js 22+
- pnpm
- A running Lavalink node

## Setup

1. Install dependencies:

   `pnpm install`

2. Configure `.env` with your Discord and Lavalink settings.

3. Build the bot:

   `pnpm build`

4. Run it:

   `pnpm prod`

## Development

- `pnpm build`
- `pnpm test`
